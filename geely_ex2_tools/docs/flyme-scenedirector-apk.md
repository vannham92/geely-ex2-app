# com.flyme.auto.scenedirector — Hướng dẫn phân tích APK (Scene Mode / 情景空间)

Tài liệu này mô tả chuyên sâu về ứng dụng hệ thống nguyên bản mang tên **Scene Mode (Chế độ Không gian)** (`com.flyme.auto.scenedirector`) bóc ra từ màn hình trung tâm của Geely **IHU629G**: bao gồm các chế độ kịch bản không gian như "Nghỉ ngơi" (Nap/Rest), "Cắm trại" (Camping), chi phối các chức năng của xe hơi thông qua **eCarX AdaptAPI** cộng hưởng với mạng **Android Car VHAL**, làm điểm tiếp nhận cổng VR-plugin của hệ eCarX và công bố dữ liệu nội bộ qua **ContentProvider** để các ứng dụng hệ thống khác lấy dùng.

**Nhãn hiện bằng Tiếng Nga trong launcher:** «Площадь места действия» (Được dịch từ khóa `application-label-ru`).  
**Nhãn Tiếng Anh (EN label):** Scene Mode. **Nhãn tiếng Trung (CN label):** 情景空间 (Không gian tình cảnh/Tùy biến cảnh).

Các thư viện hệ thống cần thiết **không bị nhồi cứng trong file APK**, nhưng được dùng rất thường xuyên:

- Gói `com.ecarx.xui.adaptapi` — Dùng mã `IWrapper`, làm bảng ánh xạ (mapping) biến các phím chức năng vendor function id → VHAL property id
- Gói `android.car` — Mượn lệnh `CarPropertyManager`
- Bộ cài `com.flyme.auto.data` — SDK chỉnh thông số cài đặt / Lớp `PreferencesProvider`
- Nền tảng điều khiển giọng nói eCarX EAS VR — Trạm `DecouplingProxy`, `SDOpenPageService`

**Trục Đỡ Hệ Sinh Thái Kéo Đẩy (Xoi Xét Qua dex/JADX):**

- Chạy Từ Đầu Làng `SceneDirectorApplication` → Đi Kêu Gọi Ổ Máy `CarHalManager.init()` → Giăng chuỗi băng rôn `AndroidStartup` (Kích Bật Voive/Giọng nói, Đạo Diễn SceneDirector, Reo Alarm/Báo Động, Nhìn VR vision, Báo Dấu Cấu UsageStats, Lấy Máy Quét Cọ Render GL renderer, Đọc Lời TTS)
- Bộ Phim Kịch Bản (Сцены): Bước Từ Cửa `BaseStartActivity` → Chẻ Nhánh `RestActivity` / Hay Qua `CampingActivity` → Vô Lõi Ruột Gan `RealRestActivity` / Nằm Rừng `RealCampingActivity`
- Khớp Lệnh Cứng HAL: Hộp Số `CarHalManager` → Kéo Đám Trùm Nhỏ `Car*Manager` + Cục Sắt Khóa `HalCommandSet` / Xả Đạn Lệnh Lẻ Tẻ `*Command`
- Lưới Màng Kẽm VR: Kêu Máy Ảo `VoiceServiceStartup` → Thọc Đầu Vào Cửa `DecouplingProxy.registerPluginCallBack` → Đụng Vào Đầu Não Nhận Lời `VoiceRecognition`
- Trạng Thái Sổ Báo Hiện Trạng: Nộp Phiếu Về `SceneProvider` (Ngõ ra `content://com.flyme.auto.scenedirector/scene`) + Móc Bọc Túi Đen Của `Settings.Secure`

### 2.1 Vòng Luân Hồi Sống Chết Đẻ Diệt Chết Trôi Dạt Của Kịch Bản (Жизненный цикл сцены)

1. **Gõ Mõ Khởi Sinh (Старт):** Bật `SceneDirector.startScene(Tên cảnh scene, Tên Mã Khe Gắn Khung Tín Gọi Lỗ Xỏ Kẹp Khe Nghe Mõm Đút Vào slotName, Xác Ma json)` → Trọc Tay Vuốt Cổ Gáy Qua Khung Kiểm Dịch Súng Hơi `StartPolicyFactory.getStartPolicy(scene).checkPrecondition()` (Đây Là Chuỗi Đóng Lệnh Chốt Kẻ Giữa Rào Kéo Nắn Nối Nhau Mốc Rào checkpoint'ov) → Bung Tay Quăng Rèm `getSceneIntent()` → Đạp Số Nổ Ga Cất Cánh `startActivity`.
2. **Kịch Bản Đang Bay Phim Sống Ảo Chiếu (Активная сцена):** Ném Quăng Tiếng Kêu Rú Trận `onSceneStart()` → Đè Nét Cầm Viết Vạch Gạch Chữ Đè Đống Trấu Lên Gáy Cuốn Sách Lệnh Sổ `SceneProvider` + Xịt Lệnh Khóa Trát Niêm Phong Sơn Tường Lên Lệnh Chốt Đỉnh `Settings.Secure sysui_alive_launcher_settings`.
3. **Giật Thẳng Thắng Ép Kéo Đuôi Dừng Cuộc Vui Nhạt Nhòa Hạ Màn (Стоп):** Nổ Còi Kết Thúc Kéo Nhấn `stopScene()` / Bật Tắt Tàn Nhẫn Đèn Màn Bứt Dây finish UI → Thằng Phía Đáy Nền Lệnh Sắt Khôi Phục Hiện Trường Rửa Bát Quét Bãi Chiến HAL Trả Đồ restore Chạy Lẩn Vòng Mạch Qua Ngõ `ExceptionService` / Bọn Mâm Sảnh Trụ Nền Hút Giới Thiệu Chống Nền Khán Lệ presenters → Sập Cửa Tối Đèn `onSceneStop()`.

## 3. Khai Thác Sổ Phong Thần Trụ Đỡ App Các Bộ Sậu Cái Ngóc Mảnh Gắn Nhãn Danh Tướng Mảng Cấu Bộ Linh Kiện Đội Lốt Danh Tướng Liệt Kê Ghi (Компоненты манифеста)
